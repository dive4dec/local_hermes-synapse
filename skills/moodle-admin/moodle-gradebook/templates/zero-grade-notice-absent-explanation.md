# Template — zero-grade notice email: student absent when sampled to explain (approved 2026-10-07, E-Quiz 4)

Companion to the per-question manual override above: when a student's quiz is zeroed for
NOT SHOWING UP when sampled in class to explain a submission, this is the notice to send.
Distinct from venue-violation formal warnings (CE-Quiz off-lab — expulsion wording IS used
there) and the older E-Quiz 2 absence notice (activity-comparison paragraphs).

Tone rules (do not regress; policy tightened 2026-10-07 — "there is simply no resources to support mitigation"):
- Factual: the ONLY cited fact is the absence at the sampling. No AI-misuse / cheating
  language — absence is not decisive evidence of either.
- State the student's recorded score explicitly (individualize per student).
- **DECISION IS FINAL.** NO invitation to explain, NO open-hour/after-lecture offer, NO
  "bring supporting evidence" line, NO explanation deadline, **NO makeup** — the user
  explicitly removed all mitigation offers from this variant (2026-10-07, after seeing
  the older softer draft). Do not re-add any of them "to be fair".
- NO expulsion threat in this variant (that belongs to venue/rule violations only).
- No technical internals (quiz IDs, DB IDs).
- Present the draft, get explicit user confirmation, THEN send (one private email per
  student via email-student-group / campus-smtp-email).

---

Subject: E-Quiz <N> — mark set to 0

Dear <First name>,

Today in class I sampled several students to explain their submissions on E-Quiz <N>, and you were not present when you were asked.

Since no explanation was given, the mark for E-Quiz <N> (your recorded score was <score>/<max>) is set to 0. This decision is final; there is no makeup opportunity for this quiz.

Regards,
<Instructor-Name>
<coursecode> Intro to Computer Programming

---

Per-question variant (student present but failed to explain ONE question, e.g.
"Jiacheng HE failed to explain Question 16"): same shape, cite the specific question by
number, "the mark for that question (<k> marks) is set to 0", same final sentence.
Subject: E-Quiz <N> — Question <k> mark set to 0. (Used 2026-10-07.)
